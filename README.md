# homebrew-tap

Homebrew formulae for [OpenLinear](https://github.com/loutab4k/OpenLinear) and [njalla-cli](https://github.com/loutab4k/njalla-cli).

```bash
brew install loutab4k/tap/openlinear
ol --help
```

The `openlinear` formula installs the CLI as `ol` (with an `openlinear` symlink).
Updated automatically by the OpenLinear release workflow.

```bash
brew install loutab4k/tap/njalla-cli
njalla-cli version
```

The `njalla-cli` formula builds from the tagged source; update its `url` and `sha256` by hand for each release.
